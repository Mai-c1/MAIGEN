# MAIGEN-api 功能完善计划

我将全权负责 `MAIGEN-api` 剩余功能的开发，重点攻克社区互动、个人中心及系统安全三大板块。

## 1. 社区模块深度完善 (Community Module)
目前社区仅有基础的下载逻辑，我将补全社交与分享属性：
- **资源分享与管理**：
    - 实现 `POST /community/share`：支持用户分享自己的题目和生成数据，关联分类与标签。
    - 实现 `GET /community/list`：支持按分类、标签筛选，按最新、最热（点赞/下载）排序。
    - 实现 `GET /community/detail/{id}`：展示详情及评分信息。
- **互动体系实现**：
    - **点赞系统**：`POST /community/like/{id}`，实现点赞/取消点赞的幂等操作。
    - **评分系统**：`POST /community/rate`，用户对资源进行 1-5 分评价，并实时更新平均分。
- **逻辑重构**：
    - 优化下载逻辑：接入 `PointsRecordService` 记录完整的积分变动流水，使用 `PointsConstants` 统一常量。

## 2. 个人中心功能闭环 (User Profile)
完善用户对自己账户的管理能力：
- **信息维护**：
    - `GET /user/info`：获取完整个人资料。
    - `PUT /user/update`：修改昵称、头像。
- **安全设置**：
    - `POST /user/password`：修改密码（校验旧密码）。
    - 预留邮箱解绑/换绑逻辑。

## 3. 管理后台与系统监控 (Admin & Ops)
为管理员提供管控能力：
- **审计与监控**：
    - 实现审计日志分页查询（对接已完成的 `operation_log`）。
    - 任务全局监控接口：查看系统当前所有任务的执行状态分布。
- **用户管控**：
    - 提供用户禁用/启用的管理接口。

## 4. 安全性加固 (Security)
- **限流保护**：基于 Redis 实现 `RateLimiter` 注解，对任务创建、签到等高频/敏感接口进行频率限制。
- **权限细化**：结合 Sa-Token 的权限注解，确保管理后台接口仅管理员可访问。

我将按照 **社区互动 -> 个人中心 -> 管理监控 -> 安全加固** 的顺序依次推进。每完成一个子模块都会同步更新 `API_SPEC.md` 文档。

如果您确认此计划，我将立即开始 **社区模块** 的 DTO 定义与核心 Service 开发。
