# 重构设计：基于数据血缘的动态回滚

你说得非常对。在 Workflow 配置完全动态且未知的情况下，依赖静态的角色名（如 "Developer"）来判断步骤类型是不可靠的。

既然步骤之间通过 `step_i_code` 共享代码信息，我们可以利用这一点。**“生成步骤”的定义应当是：在运行时实际产出了代码（`step_i_code` 不为空）的步骤。**

我们需要重构回滚逻辑，使其基于**运行时数据**（Runtime Data）而非**静态配置**（Static Config）。

## 核心变更

我们将回滚策略改为 **“寻找最近的代码生产者 (Find Last Code Producer)”**。

### 1. `AnalysisContext` 增强
增加方法用于检查某一步骤是否产出了代码。

```java
private static class AnalysisContext {
    // ... 其他字段 ...
    
    // 检查指定步骤是否有代码产出
    public boolean hasCodeOutput(Integer stepOrder) {
        String key = "step_" + stepOrder + "_code";
        return vars.containsKey(key) && StrUtil.isNotBlank((String) vars.get(key));
    }
}
```

### 2. `WorkflowNavigator` 动态回滚
`rollback` 方法不再依赖角色名，而是传入 `AnalysisContext`，通过检查历史数据来决定回退目标。

```java
public boolean rollbackToLastCodeProducer(AnalysisContext ctx) {
    // 从当前位置的前一步开始反向搜索
    for (int i = cursor - 1; i >= 0; i--) {
        AiWorkflowStepDTO step = steps.get(i);
        
        // 动态判断：如果该步骤在之前的执行中产出了代码，它就是我们的回滚目标
        if (ctx.hasCodeOutput(step.getStepOrder())) {
            cursor = i - 1; // 重置游标到该步骤之前
            return true;
        }
    }
    return false;
}
```

### 3. `handleRetry` 逻辑更新
```java
private void handleRetry(WorkflowNavigator navigator, AnalysisContext ctx, AiWorkflowStepDTO auditStep) {
    // ... 检查次数、提取意见 ...

    // 基于数据回滚
    boolean success = navigator.rollbackToLastCodeProducer(ctx);
    
    if (!success) {
        throw new RuntimeException("审计未通过，且在前序步骤中未发现任何代码产出，无法定位回滚目标。");
    }
}
```

## 整体重构结构

**文件**: `d:\web\MAIGEN2\backend\MAIGEN-analysis\src\main\java\com\maigen\analysis\service\AiAnalysisService.java`

1.  **`AnalysisContext` 类**: 封装 `Map`、`taskId`、`retryCount`、`auditAdvice` 以及 `hasCodeOutput` 辅助方法。
2.  **`WorkflowNavigator` 类**: 封装 `steps` 列表、`cursor` 指针、`next()` 和 `rollbackToLastCodeProducer(ctx)`。
3.  **`executeStep` 方法**: 封装 AI 调用、Prompt 渲染、日志、变量解析（`step_x_code`/`text`）。
4.  **`analyzeAndGenerate` 方法**: 主流程控制，使用 `while(navigator.hasNext())` 循环。

这种设计完全解耦了步骤的具体定义。无论管理员配置了多少步，叫什么名字，只要前面的步骤产出了代码，审计失败时就能准确回滚到那里。
