# MAIGEN 前端项目开发计划 (maigen-frontend)

我们将基于 **Vue 3 + Vite + TypeScript + Arco Design** 构建一个现代化的多智能体算法竞赛数据生成平台。

## 一、 基础设施与规范搭建 (Phase 1)
- **环境初始化**：在 `./frontend` 目录下完成 Vite 项目初始化。
- **依赖安装**：集成 `Arco Design` (UI), `Tailwind CSS` (布局), `Pinia` (状态), `Vue Router` (路由), `Axios` (请求), `Ace Editor` (编辑器), `ECharts` (图表)。
- **网络封装**：封装 Axios 拦截器，统一处理 Sa-Token 鉴权逻辑及全局错误提示。
- **技术文档**：编写 `FRONTEND_DOC.md` 记录组件规范与 API 对接方式。

## 二、 全局布局与主题系统 (Phase 2)
- **多主题切换**：实现“黑蓝 (Cyberpunk)”与“白蓝 (Professional)”主题切换，支持暗黑模式。
- **全局 Layout**：
  - **侧边导航栏**：仪表盘、创建任务、任务列表、社区广场、设置、管理后台。
  - **顶部 Header**：搜索框、积分显示、通知中心、用户头像下拉菜单。

## 三、 仪表盘与核心监控 (Phase 3)
- **Dashboard 实现**：
  - **数据看板**：使用 ECharts 展示任务成功率分布、积分消耗趋势。
  - **状态统计卡片**：展示任务总数、进行中 Agent、可用积分等核心指标。
  - **动态流**：展示全站最新的分享与任务完成动态。

## 四、 任务管理与编辑器集成 (Phase 4)
- **任务创建页**：
  - 左侧配置区：题目 ID、时间/内存限制、测试点数量。
  - 右侧编辑器：集成 **Ace Editor**，支持 C++ 语法高亮与 Markdown 题目描述。
- **任务执行详情**：
  - **Workflow 监控**：三段式进度条（分析中 -> 生成中 -> 验证中）。
  - **Agent 终端**：实时展示后端传回的智能体协作日志。

## 五、 社区广场 (Twitter-Style) (Phase 5)
- **极简内容流**：实现类似于 Twitter 的卡片式布局。
- **互动功能**：点赞、一键下载（扣积分逻辑）、资源评分。
- **分类标签**：顶部快速切换算法分类（如：动态规划、图论等）。

## 六、 个人中心与管理后台 (Phase 6)
- **个人中心**：资料修改、密码重置、积分流水查看。
- **管理后台**：全站任务监控看板、审计日志列表、用户禁用管理。

## 七、 性能优化与安全 (Phase 7)
- **路由懒加载**：优化首屏加载速度。
- **接口限流友好化**：前端处理 429 错误并展示友好的倒计时提示。
- **安全性**：输入校验与 XSS 防护。
