# MAIGEN 前端全重构方案 (V2.0)

## 1. 视觉风格与主题系统
- **Twitter 灵感设计**：全局应用大圆角 (`rounded-2xl`)、毛玻璃效果 (`backdrop-blur`) 和渐变背景。
- **修复配色问题**：彻底解决亮色模式下字体发白、对比度不足的 Bug。
- **五种主题色切换**：
  1. **Aurora Blue** (极光蓝)
  2. **Nebula Purple** (星云紫)
  3. **Forest Green** (科技绿)
  4. **Vulcan Red** (岩浆红)
  5. **Amber Gold** (琥珀金)
  *在 Header 提供专门的切换面板。*

## 2. 后台管理：全模块交互 (Admin Dashboard)
- **多维度管控**：在 `src/views/admin` 下实现以下模块的完整 CRUD：
  - **用户管理**：搜索、编辑、封禁、余额充值。
  - **任务监控**：全站任务列表、详情查看、违规删除。
  - **社区审计**：帖子审核（通过/驳回）、内容置顶/隐藏。
  - **积分账单**：全局积分流水查看、手动调账。
- **交互标准**：所有操作均包含确认弹窗、Loading 状态和成功提示。

## 3. 任务创建：固定费用与分布式向导
- **固定计费**：任务创建费用锁定为 **5 MAI**，简化用户心理负担。
- **三步走向导**：
  1. `Step 1: 题目属性` (名称、难度)
  2. `Step 2: 核心内容` (描述、Solution 代码)
  3. `Step 3: 费用结算` (固定 5 积分确认)

## 4. 仪表盘优先 (Dashboard First)
- **默认落地页**：登录后展示个人数据汇总。
- **核心数据看板**：包括任务趋势图、积分变动曲线、最新社区反馈。
