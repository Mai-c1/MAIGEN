## 全力推进：高性能权限体系与管理后台补全方案

### 1. 后端：高性能权限与缓存优化
- **Redis 级缓存**: 在 `MAIGEN-api/pom.xml` 中引入 `sa-token-dao-redis-jackson`。利用 Redis 缓存权限与 Session，消除鉴权时的数据库压力。
- **复合 API 增强**: 
    - 扩展 `UserVO`，增加 `roles` 与 `permissions` 字段。
    - 优化 `getUserInfo` 接口，实现“一次请求，全量鉴权数据”，减少前端网络往返。

### 2. 后端：管理后台功能全量 CRUD
- **用户管理**: 补全 `delete` (批量逻辑优化) 与 `password:reset`。
- **任务监控**: 补全 `cancel` (状态机保护)、`retry`、以及高性能日志/资源流式查看。
- **系统治理**: 实现 `backup` (异步任务) 与 `restore`。

### 3. 前端：智能鉴权与指令优化
- **响应式 Store**: 升级 Pinia `user` store，支持鉴权状态的本地缓存与同步。
- **高性能指令**: 实现 `v-permission` 指令。
- **防御性路由**: 强化全局守卫，基于动态权限列表实现无感重定向与错误拦截。

### 4. 效率与优化策略
- **批量操作**: 数据库层面优先使用批量更新/删除。
- **异步处理**: 耗时操作（如备份、AI 任务重试）均采用 RabbitMQ 异步驱动。
- **前端缓存**: 减少对 `/user/info` 的重复调用，优先使用 Store 状态。
