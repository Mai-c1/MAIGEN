# Admin 布局重构与用户模块迁移计划

根据你的指示，我们将分步执行。第一阶段**仅关注前端布局重构和用户模块的独立化**，待你确认效果后再推进其他模块。

## 目标
1.  **重构布局**: 废弃 `views/admin/index.vue` 的动态组件模式，改用标准的 `<router-view>` 嵌套路由结构。
2.  **封装组件**: 创建 `MgAdminTable` 通用 CRUD 组件。
3.  **用户模块**: 将用户管理独立为 `views/admin/user/index.vue`，并使用新组件重构。

## 详细步骤

### 1. 前端通用组件开发
*   创建 `src/components/MgAdminTable/index.vue`。
*   实现功能：
    *   **搜索栏**: 根据配置动态渲染输入框/下拉框。
    *   **表格**: 封装 `a-table`，统一处理 `loading`、`pagination`。
    *   **操作栏**: 提供插槽用于放置“新增”、“批量删除”等按钮。

### 2. 路由与布局重构
*   修改 `src/router/index.ts`:
    *   保留 `/admin` 路由，但将其 `component` 指向新的布局组件（或修改现有的 `index.vue` 仅作为 Layout）。
    *   添加子路由 `children`:
        *   `path: 'user'`, `component: () => import('@/views/admin/user/index.vue')`
        *   (其他模块暂时保留或先不注册，避免报错)
*   修改 `src/views/admin/index.vue`:
    *   移除所有业务逻辑（UserManager, TaskManager 等）。
    *   只保留侧边栏 (`a-menu`) 和主内容区 (`a-layout-content`)。
    *   将内容区改为 `<router-view />`。

### 3. 用户模块独立化 (`views/admin/user/index.vue`)
*   新建文件夹 `src/views/admin/user/`。
*   迁移 `src/views/admin/components/UserManager.vue` 的逻辑。
*   **重构**: 使用 `MgAdminTable` 替换原有的表格和搜索代码，精简代码量。
*   保留“积分调整”、“封禁”等特有逻辑，作为 Slot 插入到通用表格中。

### 4. 验证
*   启动前端，访问 `/admin/user`，确认用户列表加载正常，增删改查功能可用。

准备好后，请确认此计划。我们将从**封装 MgAdminTable 组件**开始。
