# 每日签到卡片重构计划

我们将把目前的“每日签到”卡片升级为更具吸引力的“游戏化任务中心”风格，重点突出成就感和进度感。

## 1. 视觉布局重写 (游戏化进度条风格)
- **核心数据区**：在卡片顶部居中展示“连续签到天数”，使用特大字号和渐变色，增强视觉冲击力。
- **7天周期进度条**：设计一个横向的 7 天签到链条。
  - **已签到**：显示彩色勾选图标。
  - **今日**：显示呼吸灯动效。
  - **未签到/未来**：显示灰色圆点或积分图标。
  - **第7天**：设计一个特殊的“宝箱”图标，提示连续签到 7 天的额外大奖。

## 2. 交互逻辑优化
- **状态感知**：按钮根据签到状态动态切换。
  - 未签到：显示“立即签到 +5 MAI”。
  - 已签到：显示“今日已打卡”，并伴随鼓励性文案（如“明天也要记得来哦”）。
- **简约反馈**：签到成功后，按钮平滑切换状态，上方弹出轻量级的 Message 提示。

## 3. 功能增强 (隐藏热力图)
- 将原本占据大量空间的热力图改为“历史记录”入口或卡片底部的紧凑展示，避免干扰核心的进度条视觉。

## 4. 技术实施
- **模板更新**：使用 Tailwind CSS 的 `flex` 和 `grid` 重新构建签到链条。
- **状态管理**：在 `Dashboard` 组件中增加连续天数和周进度的 Mock 数据逻辑（后续对接后端接口）。
- **样式统一**：保持毛玻璃质感，适配五种主题色。
