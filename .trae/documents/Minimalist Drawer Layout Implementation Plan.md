# 管理后台“极简抽屉流 (Minimalist Drawer)”重构计划

## 1. 布局层重构 (Layout Refactoring)
- **侧边栏优化**: 将 `admin/index.vue` 的侧边栏改为极简悬浮设计，仅保留图标或超窄边框，增加毛玻璃 (Glassmorphism) 效果。
- **主区域沉浸化**: 移除多余的容器边框，使列表视图占据核心区域，增加呼吸感。
- **全局指令栏**: 顶部增加一个 `Ctrl+K` 风格的搜索框，支持在用户、任务、内容之间快速跳转。

## 2. 组件交互升级 (Component Interaction Upgrade)
- **抽屉式表单**:
  - 重构 `UserManager.vue`：点击“新增/编辑”时，从右侧滑出 `a-drawer` 抽屉，而非弹出 `a-modal`。
  - 重构 `ContentManager.vue`：审核详情和配置修改全部移至抽屉中完成。
  - 重构 `TaskManager.vue`：任务详情通过抽屉展示，支持在不离开列表的情况下查看日志。
- **过滤器精简化**: 将零散的搜索框和下拉框整合为一个“高级过滤”按钮，默认仅展示一个全局搜索框。

## 3. 视觉与体验优化 (UI/UX Polish)
- **数据密度调整**: 优化 `a-table` 的行高和字体，使长列表更易阅读。
- **无感刷新**: 确保抽屉提交后列表平滑刷新，增加微交互动画。
- **状态感知**: 使用更精致的颜色系统（如：运行中任务使用流光进度条，锁定用户使用灰阶处理）。

## 4. 实施步骤
1. 修改 `admin/index.vue` 的主体布局。
2. 依次重构 `components/` 下的四个管理模块，将 Modal 替换为 Drawer。
3. 统一全局样式变量，确保极简风格的一致性。
4. 进行联调验证，确保所有 CRUD 功能在抽屉流下正常运行。
