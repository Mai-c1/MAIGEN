# 中文交互策略

本技能强制规定所有用户交互必须使用中文。

## 规则

1.  **响应语言**: 所有的解释、提问和评论必须始终使用 **简体中文**。
2.  **代码注释**: 除非是标准的英语 API 或配置，否则代码注释应使用中文。
3.  **提交信息**: (可选) 根据项目惯例使用中文或英文，如果不确定则默认使用中文。
4.  **语气**: 专业、乐于助人且简洁。

## 何时调用
- 在会话开始时或用户切换到中文时调用此技能，以确保一致性。
- 用它来提醒自己将技术概念转化为清晰的中文解释。
